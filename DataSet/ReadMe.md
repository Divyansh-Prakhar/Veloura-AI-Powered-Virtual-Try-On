## Dataset

This project uses the **VITON-HD dataset**, which is a high-resolution virtual try-on dataset containing images of people and corresponding clothing items.  
The dataset includes person images, clothing images, clothing masks, and parsing/pose annotations required for training and testing the virtual try-on pipeline.

Due to GitHub file size limitations, the dataset is not included in this repository.

You can download the dataset from the following link:

Dataset Download: [ADD YOUR DATASET ZIP LINK HERE]

After downloading, extract the dataset into the `datasets/` directory so the structure looks like this:

datasets/
├── train/
│   ├── image/
│   ├── cloth/
│   ├── cloth-mask/
│
└── test/
    ├── image/
    ├── cloth/
    ├── cloth-mask/
