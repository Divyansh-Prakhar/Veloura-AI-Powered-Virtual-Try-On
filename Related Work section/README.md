# Literature Review – Virtual Try-On Systems Using Deep Learning

This repository contains a **literature review document** that surveys major research works in the field of **Virtual Try-On (VTON) systems using deep learning**. The goal of the document is to understand the evolution of techniques used for generating realistic images of a person wearing different garments using computer vision and generative models.

## Overview

Virtual Try-On systems are an important application of deep learning in the fashion and e-commerce industry. These systems aim to generate realistic images by transferring clothing from product images to a person while preserving:

- Body pose
- Identity
- Garment texture and patterns
- Visual realism

The literature review summarizes key developments in this domain and highlights the challenges and research gaps that remain.

## Papers Reviewed

The document reviews the following **7 major research papers**:

1. **VITON: An Image-Based Virtual Try-On Network** (CVPR 2018)  
2. **Pix2Surf: Learning to Transfer Texture from Clothing Images to 3D Humans** (CVPR 2020)  
3. **ClothFlow: A Flow-Based Model for Clothed Person Generation** (ICCV 2019)  
4. **VITON-HD: High Resolution Virtual Try-On via Misalignment-Aware Normalization** (CVPR 2021)  
5. **GP-VTON: General Purpose Virtual Try-On via Collaborative Local-Flow Global-Parsing Learning** (CVPR 2023)  
6. **LaDI-VTON: Latent Diffusion for Virtual Try-On** (ACM Multimedia 2023)  
7. **IDM-VTON: Improving Diffusion Models for Authentic Virtual Try-On** (ECCV 2024)

## Research Motivation

Despite significant progress, existing virtual try-on systems still face several challenges such as:

- Accurate garment alignment with body pose
- Preservation of fine clothing textures
- Computational cost of diffusion-based models
- Slow inference time for real-time applications

Understanding these limitations helps guide future research directions in improving VTON systems.

## Purpose of This File

This literature review serves as a **foundation for understanding current research in virtual try-on systems** and supports further development and experimentation in this area.
